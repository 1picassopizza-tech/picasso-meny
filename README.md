# Picasso Meny

Digital menu screens for Picasso Pizzeria & Grill.

- `app.html` – the whole menu site (TV screens `/pizza`, `/mat` and the admin page `/admin`).
  Screens load this file from GitHub and pick up a new version by themselves within a few minutes.
- `loader.html` – the small page that runs on https://picasso-meny.web.app and loads `app.html`.

Prices and items are edited in the admin page, not here.
